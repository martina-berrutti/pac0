# Reglas del proyecto Paciente 0

## Datos y privacidad (NO NEGOCIABLE)

- Este proyecto NO usa datos de pacientes reales. Todos los casos son sintéticos o escritos por nosotros y validados por un estudiante avanzado o un médico.
- Nunca acceder, conectarse, consultar ni intentar leer bases de datos, sistemas o APIs de instituciones de salud (CASMU, ASSE, historia clínica electrónica, etc.).
- Nunca pedir, guardar ni procesar nombres reales, cédulas ni datos personales. Los usuarios usan un alias.
- Imágenes clínicas: solo las de assets/ con licencia registrada en CREDITS.md. Ninguna imagen clínica generada con IA.
- No copiar textos ni imágenes de libros o materiales de la facultad al producto.
- Claves de API solo en variables de entorno, nunca en el cliente ni en el repo.
- El diagnóstico del caso vive solo en el servidor; el agente paciente no lo recibe.

## Calidad

- Tipos y lint sin errores antes de hacer merge.
- Un solo caso perfecto antes de agregar otro.
- Herramienta educativa: nunca para pacientes reales.
